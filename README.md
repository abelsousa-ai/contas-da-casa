# Apps Home Assistant

Repositório de apps (add-ons) para o Home Assistant.

| App | Descrição |
|---|---|
| **Contas da casa** (`contas_da_casa`) | Importação de extractos bancários (ActivoBank e Revolut), categorização e análise das finanças da casa. |
| **Conta Corrente CLIB** (`conta_corrente_clib`) | Conta corrente com o colégio: importa facturas, notas de crédito e adiantamentos do Gmail, lê os PDFs e reparte por categoria. |

Este repositório só tem código. Os dados ficam nas bases de dados guardadas no Home Assistant (`/data` de cada app) e nunca são enviados para aqui.
